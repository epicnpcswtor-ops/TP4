# Mon projet

Description de mon projet en quelques lignes.

## Prérequis

- Python 3
- pip
- matplotlib
- numpy

## Installation

1. Cloner le dépôt
    ```sh
    git clone https://github.com/epicnpcswtor-ops/TP4/
    ```

2. Créer un environnement virtuel

3. Installer les dépendances
    ```sh
    pip install -r requirements.txt
    ```


## Utilisation

```sh
python main.py
```
